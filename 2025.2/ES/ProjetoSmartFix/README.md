# Projeto SmartFix-TB

Este é o repositório para o projeto da assistência técnica "SmartFix", conforme descrito no estudo de caso da disciplina de Engenharia de Software.

## Estrutura

- **/docs**: Contém a documentação do projeto, como diagramas UML.
- **/src**: Contém o código-fonte da aplicação, organizado por ator/funcionalidade.
- `RESPOSTA_ESTUDO_DE_CASO.md`: Resolução completa do estudo de caso proposto.

## Sprint 1 - MVP

Os arquivos na pasta `/src` representam o escopo definido para a primeira Sprint, focando em entregar o fluxo de valor principal:
1.  Cadastro de cliente e abertura de OS.
2.  Atualização de status pelo técnico.
3.  Consulta de status pelo cliente.
